# 🚚 DNATransportes

Sistema de gestão logística desenvolvido para centralizar, automatizar e dar visibilidade às operações de transporte.

Mais do que um sistema, o DNATransportes nasce com o objetivo de transformar processos logísticos manuais em uma operação inteligente, conectada e orientada por dados.

---

## 🎯 Problema

Muitas operações logísticas ainda sofrem com:

- Falta de visibilidade das entregas
- Processos descentralizados
- Controle manual em planilhas
- Dificuldade no acompanhamento de pedidos
- Falta de rastreabilidade

---

## 💡 Solução

O DNATransportes foi desenvolvido para resolver esses problemas através de uma plataforma única que integra:

- Gestão de pedidos
- Controle de rotas
- Rastreamento de entregas
- Centralização de informações
- Análise de dados operacionais

---

## ⚙️ Principais funcionalidades

- 📦 Cadastro e gerenciamento de pedidos  
- 🚚 Controle de rotas e motoristas  
- 📍 Rastreamento de entregas (em evolução)  
- 📊 Dashboard com indicadores logísticos  
- 🧾 Importação de notas fiscais (XML)  
- 👥 Gestão de clientes e endereços  
- 📑 Histórico de movimentações  

---

## 🧠 Tecnologias utilizadas

- PHP
- Laravel
- MySQL
- Blade
- JavaScript
- Bootstrap
- Chart.js

---

## 🏗️ Arquitetura

O sistema segue uma arquitetura baseada em MVC (Model-View-Controller), garantindo:

- Organização de código
- Separação de responsabilidades
- Facilidade de manutenção e evolução
